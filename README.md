Нефинальная версия, ещё надо будет доразобраться в коде.
Для тестов:
python -m unittest -v
Тесты покрывают:
базовые операции и обработку ошибок;
ключи разных типов: строки, числа, кортежи (в том числе вложенные), смешанные;
принудительные коллизии (все ключи с одинаковым хешем), удаление из головы, середины и хвоста цепочки;

Для коллизий выбран метод цепочек, расширяем при коэффиценте >= 0.75
Вставка имеет амортизированную сложность O(1): дорогой по памяти resize происходит редко.

Реализованы требуемые методы, за следующую неделю подумаю над их некоторой оптимизацией.
